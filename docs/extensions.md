# Extensions ที่แนะนำให้ติดตั้ง 🧩

เพื่อให้การเขียนโค้ดภาษา JavaScript มีความสะดวกรวดเร็วและลดข้อผิดพลาดในการทำงานได้ดีที่สุด แนะนำให้ติดตั้งส่วนเสริม (Extensions) เหล่านี้ลงในโปรแกรม VS Code ของคุณ:

---

## 1. Extensions ยอดนิยมสำหรับนักเขียนโค้ด

*   **Prettier - Code formatter:**
    เครื่องมือช่วยจัดรูปแบบและเว้นวรรคโค้ดให้อัตโนมัติเมื่อกดเซฟไฟล์ ทำให้โค้ดของเราสะอาดและเป็นระเบียบตามมาตรฐานเดียวกัน
*   **ESLint:**
    ระบบแจ้งเตือนและชี้เป้าข้อผิดพลาด (Syntax Error) ทันทีในบรรทัดที่เราเขียนโค้ดผิดหลักไวยากรณ์ ช่วยประหยัดเวลาการแก้ไขบั๊ก
*   **Code Runner:**
    เพิ่มความสะดวกในการรันสคริปต์ เพียงแค่คลิกขวาที่ไฟล์โค้ดแล้วเลือก Run Code หรือกดปุ่ม **Play (สามเหลี่ยม)** มุมบนขวาเพื่อรันผ่าน Terminal ได้ทันที
*   **Error Lens:**
    ไฮไลต์ข้อความระบุสาเหตุข้อผิดพลาดหรือคำเตือนแสดงประกบข้างโค้ดบรรทัดนั้นๆ โดยตรง ไม่จำเป็นต้องนำเมาส์ไปชี้เพื่ออ่านรายละเอียด
*   **Bracket Pair Colorizer:**
    ช่วยจำแนกสีวงเล็บจับคู่แต่ละชั้นให้อัตโนมัติ (ปัจจุบันฟังก์ชันนี้เป็นฟีเจอร์มาตรฐานเริ่มต้นของ VS Code เวอร์ชันปัจจุบันเรียบร้อยแล้ว)

---

## ⚙️ วิธีการติดตั้ง Extensions ใน VS Code

1.  เปิดโปรแกรม **VS Code**
2.  คลิกที่ไอคอน **Extensions** ที่แถบเครื่องมือซ้ายมือสุด (หรือกดคีย์ลัด `Ctrl + Shift + X` สำหรับ Windows / `Cmd + Shift + X` สำหรับ Mac)
3.  พิมพ์ชื่อ Extension ที่ต้องการค้นหาในช่องด้านบนสุด (เช่น `Prettier` หรือ `ESLint`)
4.  คลิกปุ่ม **Install** สีน้ำเงินที่การ์ด Extension นั้นๆ
5.  เมื่อติดตั้งเสร็จเรียบร้อย ปุ่มจะเปลี่ยนเป็นเฟืองการตั้งค่า พร้อมใช้งานทันที!
