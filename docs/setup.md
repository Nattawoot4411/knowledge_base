# การติดตั้งโปรแกรม 🛠️

ในการเริ่มต้นพัฒนาโปรแกรมด้วยภาษา JavaScript สำหรับการเขียนสคริปต์อัตโนมัติ (Automation) เราจำเป็นต้องมีเครื่องมือหลัก 2 อย่างติดตั้งบนเครื่องคอมพิวเตอร์ของคุณ:

---

## 1. ติดตั้ง Visual Studio Code (VS Code)

Visual Studio Code เป็นโปรแกรม Text Editor หรือเครื่องมือแก้ไขโค้ดฟรีที่ได้รับความนิยมมากที่สุดในโลก ใช้งานง่าย เบา และปรับแต่งได้หลากหลาย

1.  เข้าไปที่เว็บไซต์ทางการ: [https://code.visualstudio.com/](https://code.visualstudio.com/)
2.  คลิกปุ่ม **Download for Windows** (หรือเลือกระบบปฏิบัติการที่คุณใช้งาน เช่น macOS, Linux)
3.  เมื่อดาวน์โหลดไฟล์ติดตั้งเสร็จสิ้น ให้เปิดโปรแกรมติดตั้งและทำตามขั้นตอนแนะนำบนหน้าจอจนกระทั่งเสร็จสมบูรณ์
4.  เปิดโปรแกรม VS Code ขึ้นมาเพื่อตรวจสอบว่าหน้าต่างโปรแกรมทำงานได้ตามปกติ

---

## 2. ติดตั้ง Node.js

Node.js เป็นสภาพแวดล้อมรันไทม์ (Runtime Environment) ที่จะช่วยให้คอมพิวเตอร์ของคุณประมวลผลและรันโค้ดภาษา JavaScript นอกเว็บเบราว์เซอร์ได้โดยตรง (ผ่าน Terminal/Command Line) ซึ่งสำคัญมากในการรันระบบทำงานอัตโนมัติ

1.  เข้าไปที่เว็บไซต์ทางการ: [https://nodejs.org/](https://nodejs.org/)
2.  แนะนำให้คลิกดาวน์โหลดเวอร์ชัน **LTS (Long Term Support)** (เช่น เวอร์ชัน 18.x หรือ 20.x) ซึ่งเป็นเวอร์ชันที่มีความเสถียรสูงสุดสำหรับผู้ใช้ทั่วไป
3.  เปิดไฟล์ติดตั้งที่ดาวน์โหลดมา กด Next ไปเรื่อยๆ จนสิ้นสุดขั้นตอนติดตั้ง
4.  **วิธีตรวจสอบว่าติดตั้งสำเร็จหรือไม่:**
    *   เปิดหน้าต่าง **Command Prompt** (พิมพ์ `cmd` ในช่องค้นหาของ Windows) หรือ **Terminal**
    *   พิมพ์คำสั่งด้านล่างนี้แล้วกด Enter:
        ```bash
        node -v
        ```
    *   ถ้าการติดตั้งถูกต้อง หน้าจอจะส่งคืนหมายเลขเวอร์ชันกลับมา เช่น `v20.11.0`
