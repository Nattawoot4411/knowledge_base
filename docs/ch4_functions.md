# บทที่ 4: การสร้างฟังก์ชัน (Functions)

เมื่อโปรแกรมคอมพิวเตอร์มีขนาดใหญ่ขึ้นและมีความซับซ้อนมากขึ้น การเขียนคำสั่งทั้งหมดเรียงต่อกันตั้งแต่บรรทัดแรกจนถึงบรรทัดสุดท้ายจะทำให้โค้ดมีความยาว จัดการได้ยาก และเกิดความซ้ำซ้อน แนวทางปฏิบัติที่ดีในการเขียนโปรแกรมคือการแบ่งย่อยกระบวนการทำงานออกเป็นส่วนๆ ที่มีหน้าที่เฉพาะเจาะจง ซึ่งเราเรียกว่า "ฟังก์ชัน" (Function) การสร้างฟังก์ชันเปรียบเสมือนการสร้างเครื่องมือหรือเครื่องจักรขนาดเล็กที่เราสามารถเรียกใช้งานกี่ครั้งก็ได้เมื่อต้องการ ช่วยให้สถาปัตยกรรมของโปรแกรมมีความเป็นระเบียบ นำกลับมาใช้ใหม่ได้ (Reusable) และง่ายต่อการตรวจสอบข้อผิดพลาด ในบทเรียนนี้เราจะศึกษาตั้งแต่โครงสร้างพื้นฐานของฟังก์ชัน ไปจนถึงเทคนิคการจัดการข้อมูลแบบซับซ้อน และรูปแบบฟังก์ชันขั้นสูง

---

## จุดประสงค์การเรียนรู้
เมื่อศึกษาบทเรียนนี้จบแล้ว ผู้เรียนควรมีความสามารถดังนี้:
*   อธิบายแนวคิด ความสำคัญ และโครงสร้างพื้นฐานของฟังก์ชันได้
*   สามารถสร้าง เรียกใช้งาน และควบคุมทิศทางการทำงานของฟังก์ชันได้
*   เข้าใจหลักการส่งผ่านข้อมูล (Parameters & Arguments) และการส่งคืนค่า (Return)
*   อธิบายและจัดการกับขอบเขตการเข้าถึงตัวแปร (Variable Scope) ได้อย่างถูกต้อง
*   ประยุกต์ใช้เทคนิคพารามิเตอร์ขั้นสูง ได้แก่ Default Parameter, Rest Parameter และ Spread Operator ได้
*   เข้าใจและสามารถเขียนฟังก์ชันรูปแบบพิเศษ เช่น ฟังก์ชันเวียนเกิด (Recursive), ฟังก์ชันนิรนาม (Anonymous) และฟังก์ชันเรียกกลับ (Callback) ได้

## 1. พื้นฐานและการประกาศฟังก์ชัน (Function Basics)

*   **หลักการสำคัญ:** ฟังก์ชันคือกลุ่มของคำสั่งที่ถูกรวบรวมไว้เป็นหมวดหมู่และตั้งชื่อกำกับไว้ เพื่อทำหน้าที่ประมวลผลงานอย่างใดอย่างหนึ่งให้เสร็จสมบูรณ์ภายในตัวเอง ฟังก์ชันจะไม่ทำงานจนกว่าจะถูก "เรียกใช้งาน" (Function Call/Invoke)
*   **รายละเอียดเชิงลึก:**
    *   **การสร้างและการเรียกใช้:** การสร้างฟังก์ชันทำได้โดยใช้คีย์เวิร์ด `function` ตามด้วยชื่อฟังก์ชัน วงเล็บ `()` และบล็อกคำสั่งที่อยู่ภายในปีกกา `{}` เมื่อต้องการให้ฟังก์ชันทำงาน ให้พิมพ์ชื่อฟังก์ชันตามด้วยวงเล็บ
    *   **ลำดับการเขียนในโค้ด (Hoisting):** ในหลายภาษาโปรแกรมรวมถึง JavaScript มีกลไกที่เรียกว่า **Hoisting** ซึ่งอนุญาตให้เราสามารถ "เรียกใช้" ฟังก์ชันในบรรทัดที่อยู่ก่อนหน้าการ "ประกาศ" ฟังก์ชันได้ หรือจะประกาศก่อนแล้วค่อยเรียกใช้ภายหลังก็ได้เช่นกัน

### ตัวอย่างประกอบ:
```javascript
// การเรียกใช้งานฟังก์ชัน (สามารถเรียกก่อนบรรทัดที่ประกาศได้)
showGreeting(); 

// การประกาศฟังก์ชัน
function showGreeting() {
    console.log("สวัสดี! ยินดีต้อนรับเข้าสู่ระบบ");
}
```

## 2. การรับและส่งคืนข้อมูลในฟังก์ชัน (Parameters and Return)

ฟังก์ชันที่มีประสิทธิภาพมักจะมีการรับข้อมูลตั้งต้นเข้าไปประมวลผล และเมื่อประมวลผลเสร็จสิ้นก็สามารถส่งมอบผลลัพธ์กลับออกมาให้โปรแกรมหลักนำไปใช้ต่อได้

### 2.1 การคืนค่าและการออกจากฟังก์ชัน (Return Statement)
*   **หลักการสำคัญ:** คีย์เวิร์ด `return` มีหน้าที่ 2 ประการหลัก คือ การส่งข้อมูลที่เป็นผลลัพธ์การคำนวณกลับไปยังจุดที่เรียกใช้ฟังก์ชัน และ การสั่งให้ฟังก์ชันยุติการทำงานโดยทันที
*   **รายละเอียดเชิงลึก:**
    *   เมื่อโปรแกรมอ่านพบคำสั่ง `return` คำสั่งอื่นๆ ที่อยู่บรรทัดถัดไปภายในฟังก์ชันนั้นจะไม่ถูกประมวลผลอีก
    *   ฟังก์ชันสามารถมี `return` ได้หลายจุด (มักใช้คู่กับคำสั่งเงื่อนไข `if`) เพื่อใช้ตรวจสอบข้อผิดพลาดและสั่งให้ออกจากฟังก์ชันก่อนกำหนดได้
    *   หากฟังก์ชันไม่มีคีย์เวิร์ด `return` หรือมีเพียงคำว่า `return` เปล่าๆ โดยไม่มีข้อมูลต่อท้าย เมื่อจบการทำงานฟังก์ชันจะส่งค่า `undefined` กลับมาโดยอัตโนมัติ

#### ตัวอย่างประกอบ:
```javascript
function checkStock(amount) {
    if (amount <= 0) {
        return "สินค้าหมด"; // ออกจากฟังก์ชันและส่งข้อความนี้กลับไปทันที
    }
    return "สินค้าพร้อมจำหน่าย จำนวน: " + amount; // ส่งค่าผลลัพธ์กลับไป
}

let stockStatus = checkStock(15);
console.log(stockStatus); 
```

### 2.2 พารามิเตอร์และอาร์กิวเมนต์ (Parameters & Arguments)
*   **หลักการสำคัญ:** ตัวแปรที่รอรับค่าตอนที่เราสร้างฟังก์ชันเรียกว่า "พารามิเตอร์" (Formal Parameter) ส่วนข้อมูลจริงที่เราส่งเข้าไปตอนเรียกใช้ฟังก์ชันเรียกว่า "อาร์กิวเมนต์" (Actual Parameter / Argument)
*   **รายละเอียดเชิงลึก:**
    *   ฟังก์ชันสามารถมีพารามิเตอร์กี่ตัวก็ได้ หรือรับข้อมูลได้หลากหลายประเภทโดยไม่ต้องระบุชนิดข้อมูลกำกับ (ในกรณีของ JavaScript)
    *   **กฎการส่งค่า:** ลำดับการส่งอาร์กิวเมนต์ต้องตรงกับลำดับของพารามิเตอร์ที่ตั้งไว้
    *   **กรณีข้อมูลไม่พอดี:**
        *   หากส่งอาร์กิวเมนต์เข้าไป **มากกว่า** พารามิเตอร์ที่รอรับ ข้อมูลส่วนเกินจะถูกเพิกเฉยทิ้งไป โดยไม่เกิด Error
        *   หากส่งอาร์กิวเมนต์เข้าไป **น้อยกว่า** พารามิเตอร์ที่รอรับ พารามิเตอร์ตัวที่ไม่มีข้อมูลส่งมาให้จะมีค่าเป็น `undefined` ซึ่งอาจทำให้การคำนวณผิดพลาดได้

#### ตัวอย่างประกอบ:
```javascript
function displayInfo(name, age) {
    console.log("ชื่อ: " + name + ", อายุ: " + age);
}

// 1. ส่งค่าครบถ้วน
displayInfo("สมชาย", 25);

// 2. ส่งค่าน้อยกว่าพารามิเตอร์ (พารามิเตอร์ตัวที่ขาดจะเป็น undefined)
displayInfo("สมหญิง"); 

// 3. ส่งค่ามากกว่าพารามิเตอร์ (ค่าส่วนเกินจะถูกเพิกเฉย)
displayInfo("สมศักดิ์", 30, "วิศวกร"); 
```

## 3. ขอบเขตของตัวแปร (Variable Scope)

*   **หลักการสำคัญ:** ตัวแปรที่ถูกประกาศในตำแหน่งที่ต่างกัน จะมีอายุการใช้งานและพื้นที่ที่สามารถถูกเรียกใช้งานได้ต่างกัน แบ่งเป็นตัวแปรระดับออบเจ็กต์/โกลบอล (Global Variable) และตัวแปรระดับท้องถิ่น (Local Variable)
*   **รายละเอียดเชิงลึก:**
    *   **Local Variable:** ตัวแปรที่ประกาศ *ภายใน* บล็อกของฟังก์ชัน (รวมถึงตัวพารามิเตอร์เองด้วย) จะถูกสร้างขึ้นเมื่อฟังก์ชันทำงาน และถูกทำลายทิ้งเมื่อฟังก์ชันจบการทำงาน ตัวแปรเหล่านี้ไม่สามารถถูกอ้างอิงหรือเรียกใช้จากภายนอกฟังก์ชันได้
    *   **Global Variable:** ตัวแปรที่ประกาศ *ภายนอก* ฟังก์ชัน จะสามารถถูกมองเห็นและถูกนำไปใช้งานหรือเปลี่ยนแปลงค่าจากโค้ดส่วนใดก็ได้ รวมถึงจากภายในฟังก์ชันด้วย
*   **ประเด็นที่ควรรู้:** การตั้งชื่อตัวแปรภายในฟังก์ชันซ้ำกับตัวแปรภายนอก จะทำให้โปรแกรมให้ความสำคัญกับตัวแปรภายในฟังก์ชัน (Local) ก่อนเสมอ

### ตัวอย่างประกอบ:
```javascript
let globalName = "สมเกียรติ"; // Global Variable

function sayHello() {
    let localMessage = "สวัสดี"; // Local Variable
    console.log(localMessage + " คุณ " + globalName); // สามารถอ่านตัวแปร Global ได้
}

sayHello();

// หากนำมาเรียกใช้นอกฟังก์ชัน บรรทัดด้านล่างนี้จะเกิด Error: localMessage is not defined
// console.log(localMessage); 
```

## 4. เทคนิคการจัดการพารามิเตอร์ขั้นสูง

ภาษาโปรแกรมยุคใหม่มีไวยากรณ์ที่ช่วยให้การจัดการพารามิเตอร์ยืดหยุ่นและทรงพลังมากขึ้น

### 4.1 Default Parameter (พารามิเตอร์ค่าเริ่มต้น)
*   **หลักการสำคัญ:** คือการตั้งค่าสำรองให้กับพารามิเตอร์เอาไว้ล่วงหน้า เพื่อป้องกันปัญหาที่ผู้ใช้งานลืมส่งข้อมูลเข้ามา (หรือตั้งใจไม่ส่ง) ซึ่งช่วยลดปัญหาค่าเป็น `undefined`
*   **ประเด็นที่ควรรู้:** กฎเหล็กของการใช้ Default Parameter คือ ต้องวางพารามิเตอร์ที่มีค่าเริ่มต้นไว้ด้านขวาสุด (ตัวท้ายสุด) เสมอ หากนำไปไว้ด้านหน้า พารามิเตอร์ที่ไม่มีค่าเริ่มต้นจะถูกเลื่อนลำดับการรับค่า ทำให้การป้อนข้อมูลตอนเรียกใช้งานเกิดความสับสนและจับคู่ข้อมูลผิดพลาด

#### ตัวอย่างประกอบ:
```javascript
// rate มีค่าเริ่มต้นคือ 7 ถ้าผู้เรียกไม่ส่งค่านี้มา ให้ใช้เลข 7
function calculateTax(price, rate = 7) {
    return price + (price * (rate / 100));
}

console.log("ราคาสินค้ารวมภาษี (อัตราเริ่มต้น 7%): " + calculateTax(100)); 
console.log("ราคาสินค้ารวมภาษี (อัตรากำหนดเอง 10%): " + calculateTax(100, 10));
```

### 4.2 Rest Parameter (การรวบข้อมูล)
*   **หลักการสำคัญ:** ใช้เมื่อเราไม่ทราบจำนวนล่วงหน้าว่าข้อมูล (Arguments) จะถูกส่งเข้ามามากน้อยเพียงใด เทคนิคนี้จะรวบรวมข้อมูลทั้งหมดที่ส่งเข้ามาเก็บไว้ในรูปแบบของ อาร์เรย์ (Array)
*   **ประเด็นที่ควรรู้:**
    *   สัญลักษณ์ที่ใช้คือ จุดสามจุด `...` นำหน้าชื่อพารามิเตอร์ (เช่น `...numbers`)
    *   ในหนึ่งฟังก์ชัน จะมี Rest Parameter ได้เพียงตัวเดียวเท่านั้น
    *   ต้องวาง Rest Parameter ไว้เป็น **ลำดับสุดท้าย** ของพารามิเตอร์ทั้งหมดเสมอ

### 4.3 Spread Operator (การกระจายข้อมูล)
*   **หลักการสำคัญ:** ทำงานตรงข้ามกับ Rest Parameter โดยใช้สัญลักษณ์ `...` เช่นเดียวกัน แต่ใช้ในฝั่งของ "การเรียกใช้งานฟังก์ชัน" หน้าที่ของมันคือการนำอาร์เรย์หรือกลุ่มข้อมูลมากระจายแตกออกเป็นชิ้นๆ เพื่อป้อนเข้าเป็นอาร์กิวเมนต์แบบรายตัว

#### ตัวอย่างประกอบ:
```javascript
function findMaximum(...scores) { // Rest: รวบค่าเป็นอาร์เรย์ scores
    let max = scores[0];
    for (let score of scores) {
        if (score > max) {
            max = score;
        }
    }
    return max;
}

let studentGrades = [85, 92, 78, 99, 88];
let maxGrade = findMaximum(...studentGrades); // Spread: กระจายข้อมูลในอาร์เรย์ส่งไปทีละตัว
console.log("คะแนนสูงสุดคือ: " + maxGrade);
```

## 5. รูปแบบการใช้งานฟังก์ชันขั้นสูง (Advanced Functions)

### 5.1 Recursive Function (ฟังก์ชันเวียนเกิด)
*   **หลักการสำคัญ:** คือฟังก์ชันที่ออกแบบมาให้ "เรียกใช้งานตัวเอง" ซ้ำๆ ซ้อนกันลงไปเรื่อยๆ ภายในบล็อกคำสั่งของตัวมันเอง
*   **ประเด็นที่ควรรู้:** การเขียนฟังก์ชันประเภทนี้ จำเป็นต้องมี **จุดหยุด (Base Case)** เสมอ หากไม่มีกลไกให้หยุดเรียกตัวเอง โปรแกรมจะทำงานวนลูปไม่รู้จบจนหน่วยความจำเต็มและล่มในที่สุด (Stack Overflow)

#### ตัวอย่างประกอบ:
```javascript
function countDown(number) {
    // จุดหยุด (Base Case)
    if (number <= 0) {
        console.log("สิ้นสุดการนับถอยหลัง!");
        return;
    }
    console.log(number);
    countDown(number - 1); // เรียกตัวเองซ้ำโดยลดค่าลง 1
}

countDown(3);
```

### 5.2 Anonymous Function (ฟังก์ชันนิรนาม)
*   **หลักการสำคัญ:** คือการสร้างฟังก์ชันขึ้นมาโดยไม่ตั้งชื่อกำกับ นิยมใช้โดยการนำไปกำหนดค่าเป็นตัวแปร (Assign to variable) ทำให้ตัวแปรนั้นมีสถานะเป็นฟังก์ชัน
*   **ประเด็นที่ควรรู้:** เมื่อประกาศฟังก์ชันลักษณะนี้เพื่อเก็บลงตัวแปร ไวยากรณ์บังคับว่าจะต้องปิดท้ายบล็อกปีกกาด้วยเครื่องหมายเซมิโคลอน `;` เสมอ

#### ตัวอย่างประกอบ:
```javascript
const calculateArea = function(width, height) {
    return width * height;
}; // ต้องมี ; ปิดท้าย

console.log("พื้นที่สี่เหลี่ยมคือ: " + calculateArea(5, 10));
```

### 5.3 Callback Function (ฟังก์ชันเรียกกลับ)
*   **หลักการสำคัญ:** คือการที่เราส่ง "ฟังก์ชันหนึ่ง" เข้าไปเป็นอาร์กิวเมนต์ให้กับ "อีกฟังก์ชันหนึ่ง" เพื่อให้ฟังก์ชันหลักทำงานของตนเองให้เสร็จก่อน แล้วจึงทำการรัน (Call back) ฟังก์ชันที่เราส่งไปให้ในภายหลัง
*   **ประเด็นที่ควรรู้:** นิยมใช้มากในกระบวนการทำงานแบบไม่พร้อมเพรียงกัน (Asynchronous) หรือใช้ร่วมกับฟังก์ชันนิรนามเพื่อกำหนดพฤติกรรมการทำงานเฉพาะกิจ

#### ตัวอย่างประกอบ:
```javascript
function processData(data, callback) {
    // สมมติว่าทำการประมวลผลข้อมูลเสร็จสิ้นแล้ว
    let result = data + " Processed";
    
    // เรียกใช้ฟังก์ชันที่ถูกส่งเข้ามา
    callback(result); 
}

// ใช้งานโดยส่ง Anonymous function เข้าไปเป็น Callback
processData("Document1", function(finalOutput) {
    console.log("งานเสร็จแล้ว ผลลัพธ์คือ: " + finalOutput);
});
```

## สรุปบทเรียน
ฟังก์ชันเป็นหัวใจสำคัญที่ช่วยยกระดับการเขียนโค้ดจากการเรียงบรรทัดธรรมดา ไปสู่การจัดโครงสร้างที่มีระบบ เราสามารถส่งข้อมูลเข้าสู่ฟังก์ชันผ่าน Parameters และรับผลลัพธ์กลับผ่าน Return การทำความเข้าใจเรื่องขอบเขตของตัวแปร (Scope) จะช่วยป้องกันข้อบกพร่องของโปรแกรมได้ นอกจากนี้ไวยากรณ์สมัยใหม่ เช่น Default, Rest Parameter และ Spread Operator ยังช่วยให้จัดการกับข้อมูลที่ซับซ้อนและมีจำนวนไม่แน่นอนได้ง่ายขึ้น ท้ายที่สุด การประยุกต์ใช้ Anonymous และ Callback Function ถือเป็นทักษะขั้นสูงที่จำเป็นอย่างยิ่งในการเขียนโปรแกรมสมัยใหม่ที่ต้องมีการเชื่อมโยงการทำงานหลายส่วนเข้าด้วยกัน

## ❓ คำถามทบทวน (Review Questions)

1. **การใช้ฟังก์ชันมีข้อดีเหนือกว่าการเขียนโค้ดทุกอย่างรวมกันในส่วนหลักของโปรแกรมอย่างไร?**
   <details spellcheck="false" data-lt-active="false" data-gramm="false" data-gramm_editor="false">
     <summary>ดูเฉลยคำตอบ</summary>
     <div class="details-content">

     </div>
   </details>

2. **หากเราเรียกใช้งานฟังก์ชันในบรรทัดที่อยู่ก่อนหน้าตำแหน่งที่มีการประกาศฟังก์ชันนั้นในโค้ด โปรแกรมจะทำงานได้หรือไม่ เพราะเหตุใด?**
   <details spellcheck="false" data-lt-active="false" data-gramm="false" data-gramm_editor="false">
     <summary>ดูเฉลยคำตอบ</summary>
     <div class="details-content">
       ทำงานได้ หากประกาศฟังก์ชันแบบธรรมดา (Function Declaration) เนื่องจากมีกลไกที่เรียกว่า <strong>Hoisting</strong> ของภาษา JavaScript ที่จะยกการประกาศฟังก์ชันขึ้นไปไว้ด้านบนสุดของสโคปก่อนเริ่มทำงานจริง
     </div>
   </details>

3. **คีย์เวิร์ด return มีหน้าที่หลัก 2 อย่าง อะไรบ้าง?**
   <details spellcheck="false" data-lt-active="false" data-gramm="false" data-gramm_editor="false">
     <summary>ดูเฉลยคำตอบ</summary>
     <div class="details-content">
       1. ส่งข้อมูลที่เป็นผลลัพธ์จากการประมวลผลภายในฟังก์ชันกลับคืนไปยังจุดที่เรียกใช้งานฟังก์ชัน<br>2. ยุติการทำงานของฟังก์ชันนั้นในทันที
     </div>
   </details>

4. **ความแตกต่างระหว่างคำว่า Parameter และ Argument ในบริบทของฟังก์ชันคืออะไร?**
   <details spellcheck="false" data-lt-active="false" data-gramm="false" data-gramm_editor="false">
     <summary>ดูเฉลยคำตอบ</summary>
     <div class="details-content">
       <strong>Parameter</strong> คือ ตัวแปรที่ตั้งชื่อรับไว้ในวงเล็บตอนประกาศสร้างฟังก์ชัน ส่วน <strong>Argument</strong> คือ ข้อมูลจริง (เช่น ตัวเลข สตริง ตัวแปร) ที่เราส่งเข้าไปให้ฟังก์ชันใช้งานขณะเรียกใช้ฟังก์ชันจริง
     </div>
   </details>

5. **หากสร้างฟังก์ชันที่รับพารามิเตอร์ 3 ตัว แต่ตอนเรียกใช้งานส่งอาร์กิวเมนต์เข้าไปเพียง 2 ตัว จะเกิดผลลัพธ์อย่างไรกับพารามิเตอร์ตัวที่ 3?**
   <details spellcheck="false" data-lt-active="false" data-gramm="false" data-gramm_editor="false">

     <div class="details-content">
       พารามิเตอร์ตัวที่ 3 จะมีค่าเป็น <code>undefined</code> ซึ่งถ้าหากไม่มีการจัดการหรือไม่มี Default Parameter ตั้งค่าสำรองไว้ อาจนำไปสู่การคำนวณที่ผิดพลาดหรือได้ผลลัพธ์เป็น <code>NaN</code>
     </div>
   </details>

6. **อธิบายความแตกต่างระหว่างตัวแปรแบบ Local และ Global Variable ในแง่ของขอบเขตการเข้าถึง**
   <details spellcheck="false" data-lt-active="false" data-gramm="false" data-gramm_editor="false">
     <summary>ดูเฉลยคำตอบ</summary>
     <div class="details-content">
       <strong>Local Variable</strong> คือ ตัวแปรที่ประกาศภายในฟังก์ชัน สามารถเรียกใช้งานได้เฉพาะในฟังก์ชันนั้นและจะสลายไปเมื่อฟังก์ชันทำงานเสร็จ ส่วน <strong>Global Variable</strong> คือ ตัวแปรที่ประกาศภายนอกฟังก์ชัน ซึ่งส่วนใดของโค้ดโปรแกรม (รวมถึงในฟังก์ชันอื่นๆ) ก็สามารถเข้าถึงและแก้ไขค่าได้
     </div>
   </details>

7. **หากต้องการกำหนดพารามิเตอร์ที่มีค่าเริ่มต้น (Default Parameter) ควรวางตำแหน่งพารามิเตอร์นั้นไว้ส่วนใดของวงเล็บ และเพราะเหตุใด?**
   <details spellcheck="false" data-lt-active="false" data-gramm="false" data-gramm_editor="false">
     <summary>ดูเฉลยคำตอบ</summary>

     </div>
   </details>

8. **ความแตกต่างระหว่าง Rest Parameter และ Spread Operator แม้จะใช้สัญลักษณ์ ... เหมือนกัน คืออะไร?**
   <details spellcheck="false" data-lt-active="false" data-gramm="false" data-gramm_editor="false">

     </div>
   </details>

9. **"จุดหยุด" หรือ Base Case มีความสำคัญอย่างไรในการสร้าง Recursive Function?**

10. **Callback Function คืออะไร และมักจะถูกนำไปใช้งานร่วมกับฟังก์ชันประเภทใดบ่อยที่สุด?**
