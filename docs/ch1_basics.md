# บทที่ 1: Introduction

การเขียนจาวาสคริปต์ให้สามารถทำงานได้ตรงความต้องการ มีทฤษฎีและโครงสร้างของภาษาเบื้องต้นที่ต้องเรียนรู้ดังนี้:

---

## 1. โครงสร้างของภาษา JavaScript เบื้องต้น (Syntax)

มีกฎพื้นฐานในการเขียนและจัดระเบียบโค้ดที่คุณควรจำไว้ใช้งาน:

*   **Case-Sensitive:** ตัวอักษรพิมพ์เล็กและพิมพ์ใหญ่มีค่าทางภาษาโปรแกรมแตกต่างกันโดยสิ้นเชิง ตัวแปรชื่อ `name`, `Name` และ `NAME` จะถูกมองเป็นตัวแปร 3 ตัวที่แยกขาดจากกัน
*   **เซมิโคลอน (Semicolon: `;`):** นิยมใส่เครื่องหมายเซมิโคลอนไว้ท้ายแถวคำสั่ง เพื่อบอกล่ามแปลภาษาของโปรแกรมว่าจบหนึ่งคำสั่งบรรทัดนั้นๆ แล้ว 

---

## 2. การรันโค้ด JavaScript

เราสามารถรันคำสั่ง JavaScript เพื่อดูผลลัพธ์ผ่าน 2 ช่องทางหลัก:

1.  **ผ่านเบราว์เซอร์ (Browser Console):** กดปุ่ม `F12` บนแป้นพิมพ์ขณะใช้งานเว็บเบราว์เซอร์ แล้วเลือกแท็บ **Console** จากนั้นลองพิมพ์คำสั่งทดสอบรันดูได้ทันที
2.  **ผ่าน Node.js (Terminal):** เป็นแนวทางหลักสำหรับงาน Automation โดยเขียนโค้ดบันทึกลงไฟล์แล้วเปิดหน้าต่าง Command Line/Terminal พิมพ์รันผ่านคำสั่ง `node ชื่อไฟล์.js`

---

## 3. การคอมเมนต์โค้ด และ คำสั่งแสดงผล

*   **คอมเมนต์ (Comments):** การเขียนข้อความอธิบายการทำงานภายในบรรทัดโค้ดเพื่อให้กลับมาอ่านแล้วเข้าใจได้ง่าย โดยระบบคอมพิวเตอร์จะไม่อ่านบรรทัดนี้ไปรัน
    *   `//` สำหรับคอมเมนต์บรรทัดเดียว
    *   `/* ... */` สำหรับครอบคอมเมนต์ยาวหลายบรรทัด
*   **คำสั่งแสดงผล console.log():** ใช้พิมพ์หรือพ่นข้อมูลออกมาตรวจสอบทางหน้าจอ
    ```javascript
    console.log("ข้อความที่ต้องการแสดง");
    ```

---
## 4. สิ่งที่ควรพิจารณาเติมเพิ่ม
1. กฎการตั้งชื่อ (Naming Conventions):
    การตั้งชื่อตัวแปรและฟังก์ชันแบบอูฐ หรือ camelCase (เช่น myVariableName, productionRate) เข้าไปในส่วนของ Syntax เพราะเป็นมาตรฐานสากลของ JavaScript ที่คนเรียนต้องใช้ไปตลอด

---
## 💻 แบบฝึกหัดท้ายบทเรียน (Workshop)

**โจทย์:**

1. สร้างโฟลเดอร์สำหรับโปรเจกต์ของคุณบนคอมพิวเตอร์ แล้วเปิดโฟลเดอร์นั้นด้วยโปรแกรม VS Code
2. สร้างไฟล์เปล่าตัวใหม่ขึ้นมาและเซฟตั้งชื่อว่า `app.js`
3. พิมพ์คำสั่งสำหรับทักทายลงในไฟล์ดังนี้:

    ```
    console.log("Hello Automation World!");
    ```

4. เปิด Terminal ใน VS Code (คลิกเมนู **Terminal > New Terminal**)
5. พิมพ์คำสั่งรันไฟล์: `node app.js` แล้วกด Enter
6. ตรวจสอบว่าหน้าจอแสดงคำว่า `Hello Automation World!` ขึ้นมาหรือไม่
