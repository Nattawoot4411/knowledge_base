    บทที่ 2: ตัวแปร (Variables)

    ตัวแปรเปรียบเสมือนกล่องสำหรับเก็บข้อมูลในโปรแกรมของเรา เพื่อที่โปรแกรมจะได้จำและนำข้อมูลนั้นมาใช้คำนวณหรือแสดงผลได้ในภายหลัง

    ในภาษา JavaScript เรานิยมใช้คำสำคัญ (Keywords) ในการประกาศตัวแปรอยู่ 2 รูปแบบหลักๆ:

    1. คำสั่ง let

    ใช้สำหรับประกาศตัวแปรที่มีการเปลี่ยนแปลงค่าได้ในภายหลัง (Re-assignable)

    let name = "John";
name = "Jane"; // สามารถเปลี่ยนค่าตัวแปร name เป็น "Jane" ได้โดยไม่มีปัญหา
console.log(name); // แสดงผล: Jane

    2. คำสั่ง const

    ย่อมาจาก Constant ใช้สำหรับประกาศตัวแปรที่เป็นค่าคงที่ ไม่สามารถเปลี่ยนแปลงค่าได้อีกตลอดอายุของโปรแกรม

    const pi = 3.14;
// pi = 3.14159; // หากลองเปลี่ยนค่าแบบนี้ จะเกิดข้อผิดพลาด (TypeError)
console.log(pi); // แสดงผล: 3.14

    💻 แบบฝึกหัดท้ายบทเรียน (Workshop)

    โจทย์: 1. ทดลองตั้งตัวแปรชื่อ name และใช้คำสั่ง let เพื่อเก็บชื่อของคุณ 2. ตั้งตัวแปรชื่อ pi ด้วยคำสั่ง const เพื่อเก็บค่า 3.14 3. แสดงผลตัวแปรเหล่านั้นออกมาด้วยคำสั่ง console.log() 4. ลองตรวจสอบในแท็บ Console ทางขวามือเมื่อรันโค้ด
