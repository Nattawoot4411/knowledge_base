    บทที่ 2: ตัวแปร ชนิดข้อมูล และโอเปอเรเตอร์

    ในบทเรียนนี้ เราจะเจาะลึกเข้าไปสู่โครงสร้างหัวใจสำคัญของการเขียนโปรแกรมด้วยภาษา JavaScript ได้แก่ การเก็บข้อมูลในตัวแปร ชนิดของข้อมูลแบบต่างๆ และการจัดการประมวลผลข้อมูลเหล่านั้นด้วยเครื่องหมายการคำนวณและตัวดำเนินการ (Operators)

    1. หลักการกำหนดและการตั้งชื่อตัวแปร (Naming Variables)

    ตัวแปร (Variable) คือกล่องสำหรับใช้อ้างอิงหรือจัดเก็บข้อมูลเพื่อนำไปใช้คำนวณ แสดงผล หรือเปลี่ยนแปลงค่าในภายหลัง การตั้งชื่อตัวแปรใน JavaScript มีกฎเกณฑ์ที่สำคัญดังนี้:

    • ตัวอักษรที่อนุญาต: ต้องประกอบด้วยตัวอักษรภาษาอังกฤษ a-z, A-Z, ตัวเลข 0-9, เครื่องหมายขีดล่าง (Underscore: _) หรือสัญลักษณ์ดอลลาร์ (Dollar Sign: $) เท่านั้น
    • ห้ามขึ้นต้นด้วยตัวเลข: เช่น num1 (ถูกต้อง) แต่ 1num (ไม่ถูกต้อง)
    • ห้ามมีช่องว่างหรืออักขระพิเศษอื่นๆ: เช่น myVar (ถูกต้อง) แต่ my Var หรือ my&Var (ไม่ถูกต้อง)
    • เป็น Case-Sensitive: ตัวพิมพ์เล็กและใหญ่ถือเป็นคนละตัวแปรกันอย่างสิ้นเชิง เช่น age, Age, และ AGE แยกขาดจากกันทั้งหมด
    • ห้ามใช้คำสงวน (Reserved Keywords): เช่น var, let, const, if, for, class

    มาตรฐานที่เป็นนิยม (Naming Conventions)

    ในภาษา JavaScript นิยมตั้งชื่อตัวแปรและฟังก์ชันด้วยสไตล์ camelCase (อูฐ) โดยเริ่มต้นด้วยตัวอักษรพิมพ์เล็ก หากมีหลายคำรวมกัน ให้คำถัดไปขึ้นต้นด้วยตัวพิมพ์ใหญ่ เช่น numProducts, isValidInput, dayOfMonth

    ลักษณะการตั้งชื่อที่ ถูกต้อง ลักษณะการตั้งชื่อที่ ไม่ถูกต้อง (Error) สาเหตุที่ผิดพลาด
    x, _x, $ 1stName ขึ้นต้นด้วยตัวเลข
    num1, firstname a&b มีอักขระพิเศษ &
    english2thai var ใช้คำสงวนของภาษา
    date_month_year, us$dollar my name มีช่องว่างระหว่างคำ

    2. การประกาศตัวแปรและการกำหนดค่า (Variable Declaration & Assignment)

    ก่อนที่จะเรียกใช้งานตัวแปร เราจำเป็นต้องสร้างหรือประกาศตัวแปรขึ้นมาก่อน โดย JavaScript มีคีย์เวิร์ดหลัก 3 ตัวในการประกาศดังนี้:

    2.1 คีย์เวิร์ดประกาศตัวแปร var vs let vs const

    • var: คำสั่งดั้งเดิมของ JavaScript (ปัจจุบันหลีกเลี่ยงการใช้งานเพื่อป้องกันปัญหาสโคปตัวแปรทับซ้อน) สามารถประกาศซ้ำในสโคปเดิมได้
    • let: คีย์เวิร์ดมาตรฐานใหม่ (เปิดตัวใน ES6 / ES2015) เป็นแบบ Block-scoped (ทำงานเฉพาะในบล็อกวงเล็บปีกกา {} ที่สลักไว้) และ ไม่สามารถประกาศซ้ำในสโคปเดียวกันได้ (แต่เปลี่ยนค่าได้)
    • const: สำหรับประกาศ ค่าคงที่ (Constant) ที่เมื่อกำหนดค่าเริ่มต้นแล้วจะไม่สามารถแก้ไขหรือเปลี่ยนค่าใหม่ได้ และต้องกำหนดค่าทันทีที่ประกาศ

    // ตัวแปรที่เปลี่ยนค่าได้ (Reassignable)
let price = 100;
price = 120; // ทำได้ปกติ

// ค่าคงที่ที่เปลี่ยนค่าไม่ได้ (Immutable Reference)
const PI = 3.14159;
// PI = 3.14; // จะเกิด Error: Assignment to constant variable.

    2.2 รูปแบบการประกาศและกำหนดค่า

    เมื่อเราประกาศตัวแปรโดยไม่มีการกำหนดค่าเริ่มต้น ค่าเริ่มต้นทางภาษาของมันจะเป็น undefined เสมอ ซึ่งเราสามารถเขียนระบุค่าได้หลากหลายรูปแบบ:

    แบบที่ 1: ประกาศตัวแปรก่อน แล้วกำหนดค่าในภายหลัง

    let text;
text = "Hello World";

    แบบที่ 2: ประกาศและกำหนดค่าเริ่มต้นทันที (Initialization)

    let score = 0;

    แบบที่ 3: ประกาศตัวแปรหลายตัวพร้อมกันในบรรทัดเดียว (คั่นด้วยเครื่องหมายจุลภาค ,)

    let x, y, z; // ได้ค่า undefined ทั้ง 3 ตัว
let a = 1, b = 2, c = 3;
let width, height = 50, depth; // กำหนดค่าเฉพาะ height เป็น 50 ส่วนตัวอื่นเป็น undefined

    3. ชนิดข้อมูลพื้นฐาน (Primitive Data Types)

    ภาษา JavaScript เป็นภาษาประเภท Loosely Typed หมายความว่าเราไม่ต้องกำหนดชนิดข้อมูลล่วงหน้าขณะประกาศ และตัวแปรสามารถเปลี่ยนชนิดข้อมูลที่จัดเก็บข้ามประเภทไปมาได้ตลอดเวลา

    let item = 100;      // ตอนแรกจัดเก็บข้อมูล Number
item = "One Hundred"; // เปลี่ยนไปเก็บข้อมูล String ได้โดยไม่เกิด Error

    ชนิดข้อมูลพื้นฐานที่จำเป็นต้องทราบมีดังนี้:

    3.1 ข้อมูลชนิดตัวเลข (Number)

    ครอบคลุมทั้งจำนวนเต็ม (Integer) ทศนิยม (Float) และจำนวนติดลบ ในการพิมพ์ตัวเลข ห้ามใส่เครื่องหมายจุลภาคคั่น (เช่น 123,456 จะเกิด Error) * ข้อมูลเพิ่มเติม: ใน JavaScript มาตรฐานใหม่ (ES2021) สามารถใช้เครื่องหมายขีดล่าง _ คั่นสายตาเพื่อให้กระชับสายตาได้ เช่น let salary = 1_000_000; (ซึ่งมีค่าเท่ากับ 1000000)

    let age = 25;        // จำนวนเต็ม
let temp = -5.5;     // จำนวนติดลบและทศนิยม
let num = 007;       // ค่าเท่ากับ 7

    3.2 ข้อมูลชนิดข้อความ (String)

    คือข้อความอักขระที่ครอบด้วยเครื่องหมายอัญประกาศ ซึ่งเราเลือกใช้ได้ 3 รูปแบบ: 1. Double Quotes ("..."): "JavaScript" 2. Single Quotes ('...'): 'JavaScript' 3. Backticks (`...`): สำหรับสร้าง Template Literals (ดูรายละเอียดเพิ่มเติมในข้อ 4.8)

    การเขียนข้อความหลายบรรทัด (Multi-line String)

    หากเรากดขึ้นบรรทัดใหม่ตรงๆ ภายในเครื่องหมายอัญประกาศคู่หรือเดี่ยวธรรมดา จะทำให้ระบบแปลภาษาเกิดการสับสนและ Error ได้ เรามีวิธีแก้ 3 แบบดังนี้:

    // วิธีที่ 1: ใส่ Backslash (\) ไว้ท้ายบรรทัดที่ต้องการขึ้นต่อ
let text1 = "Lorem Ipsum is simply dummy text \
of the printing and \
typesetting industry";

// วิธีที่ 2: แยกเป็นสตริงย่อยแล้วนำมารวมกันด้วยเครื่องหมายบวก (+)
let text2 = "Lorem Ipsum is simply dummy text " +
            "of the printing and " +
            "typesetting industry";

// วิธีที่ 3: ใช้เครื่องหมาย Backtick (`) ครอบคลุมหลายบรรทัดได้โดยตรง (ดีที่สุด)
let text3 = `Lorem Ipsum is simply dummy text
of the printing and
typesetting industry`;

    อักขระพิเศษ (Escape Characters)

    ใช้สำหรับการแทรกสัญลักษณ์พิเศษที่พิมพ์ลงในข้อความสตริงตรงๆ ไม่ได้: * \n: ขึ้นบรรทัดใหม่ (New Line) * \t: เว้นระยะ 1 แท็บ (Tab) * \": ใส่เครื่องหมายคำพูดคู่ลงไปในข้อความที่เป็น Double Quotes * \': ใส่เครื่องหมายคำพูดเดี่ยวลงไปในข้อความที่เป็น Single Quotes * \\: แสดงเครื่องหมาย Backslash

    3.3 ข้อมูลชนิดบูลีน (Boolean)

    มีค่าสถานะเพียง 2 ค่าเท่านั้นคือ true (จริง) หรือ false (เท็จ) เท่านั้น (พิมพ์พิมพ์เล็กทั้งหมด)

    let isLogged = true;
let hasError = false;
// let status = True; // Error! คำว่า True พิมพ์ใหญ่ไม่ใช่คีย์เวิร์ดบูลีน

    3.4 ค่าพิเศษในระบบตัวเลขและระบบวัตถุ

    • null: แปลว่า "ไม่มีค่า" หรือ "ค่าว่างเปล่า" มักใช้กำหนดให้กับตัวแปรเพื่อระบุว่าตั้งใจให้มันว่าง (โดยเฉพาะกับการจัดการกับ Object)
    • undefined: แปลว่า "ยังไม่ได้กำหนดค่าใดๆ" มักเกิดตอนประกาศตัวแปรแล้วปล่อยว่างไว้ หรืออ้างอิงถึงตัวแปรที่ยังไม่มีตัวตนอยู่จริง
      • ข้อสังเกต: typeof null จะคืนค่าเป็น "object" (ซึ่งเป็นช่องโหว่ทางดีไซน์ดั้งเดิมของภาษาจาวาสคริปต์) ในขณะที่ typeof undefined จะคืนค่าเป็น "undefined"
    • NaN (Not a Number): ค่าพิเศษทางคณิตศาสตร์แปลว่า "ไม่ใช่ตัวเลข" เกิดขึ้นจากการคำนวณที่ผิดพลาดหรือไม่ได้ผลลัพธ์ที่เป็นตัวเลข เช่น เอาตัวเลขไปคำนวณคณิตศาสตร์ร่วมกับข้อความ
      • ตัวอย่าง: 30 - "Minutes" หรือ "Hello" * "World" หรือ 0 / 0
      • การตรวจสอบ: สามารถใช้ฟังก์ชัน isNaN(ค่าที่ต้องการตรวจ) เพื่อเช็คได้ เช่น isNaN("100Bath") จะได้ค่าเป็น true
      • ข้อควรระวัง: สำหรับค่า null หากนำไปบวกลบคูณหารปกติ จาวาสคริปต์จะแปลงค่า null ให้เทียบเท่าตัวเลข 0 เสมอ (เช่น null + 10 จะได้ 10 ไม่ใช่ NaN)
    • Infinity / -Infinity: ค่าอนันต์เชิงบวก/ลบ เกิดขึ้นเมื่อหารตัวเลขใดๆ ที่ไม่ใช่ศูนย์ ด้วยศูนย์ (เช่น 1 / 0 ได้ Infinity) หรือกำหนดตัวเลขที่มีค่าสูงเกินความจุสูงสุดที่ระบบรองรับตัวเลขปกติได้ (1.7976931348623157e+308)
      • การตรวจสอบ: ใช้ฟังก์ชัน isFinite(ค่าที่ต้องการตรวจ) เพื่อตรวจเช็คว่าค่านั้นไม่ใช่ Infinity หรือ NaN หรือไม่

    4. ตัวดำเนินการ (Operators)

    4.1 เครื่องหมายกำหนดค่า (Assignment Operator: =)

    ใช้สำหรับการส่งค่าจากฝั่งขวาไปเก็บไว้ในตัวแปรฝั่งซ้าย และสามารถเขียนแบบเชื่อมโยงกันหลายๆ ตัวแปรเพื่อกำหนดค่าเดียวพร้อมกันได้ (เรียกว่า Chaining Assignment โดยระบบจะประมวลผลจากขวาไปซ้าย):

    let x, y, z;
x = y = z = 10; // ทั้ง x, y, z จะเก็บค่า 10 เหมือนกันทั้งหมด

    4.2 เครื่องหมายทางคณิตศาสตร์ (Arithmetic Operators)

    ประมวลผลคำนวณตัวเลข: * + (บวก), - (ลบ), * (คูณ), / (หาร) * % (Modulo / หารเอาเศษ): หาเศษจากการหาร เช่น 10 % 3 ได้ผลเศษเป็น 1 หรือ 12 % 3.5 ได้เศษเป็น 1.5 * ** (Exponentiation / ยกกำลัง): เช่น 10 ** 2 ได้ผลลัพธ์เป็น 100 (เทียบเท่าคำสั่ง Math.pow(10, 2))

    [!WARNING] หากใช้โอเปอเรเตอร์คณิตศาสตร์ (-, *, /, **) ร่วมกับตัวเลขที่อยู่ในฟอร์แมตข้อความ (เช่น "100" * "10") จาวาสคริปต์จะแปลงชนิดข้อมูลให้อัตโนมัติและหาค่าให้เสร็จสิ้นเป็นจำนวนตัวเลขปกติ

    แต่สำหรับเครื่องหมาย บวก (+) จะถูกมองเป็นการ เชื่อมต่อข้อความ (String Concatenation) ทันทีหากมีฝั่งใดฝั่งหนึ่งเป็นข้อความ เช่น 108 + '1009' จะส่งผลลัพธ์เป็นข้อความต่อกันยืดๆ ว่า "1081009"

    4.3 เครื่องหมายคำนวณและกำหนดค่าร่วม (Compound Assignment)

    ลดรูปการเขียนคำนวณค่าตัวแปรตัวเดิมแล้วเขียนทับค่าตัวเอง: * x += 10 ลดรูปจาก x = x + 10 * x -= 50 ลดรูปจาก x = x - 50 * x *= 2 ลดรูปจาก x = x * 2 * x /= 20 ลดรูปจาก x = x / 20 * x %= 3 ลดรูปจาก x = x % 3 * x **= 3 ลดรูปจาก x = x ** 3

    4.4 โอเปอเรเตอร์เพิ่ม/ลดค่าทีละ 1 (Increment & Decrement)

    • ++ (บวกเพิ่มขึ้น 1), -- (ลดลง 1) โดยแยกออกเป็น 2 รูปแบบที่ส่งผลการคำนวณในนิพจน์ต่างกัน:
      1. Prefix (วางไว้ด้านหน้า เช่น ++x): ทำการบวก/ลดค่าของ x ก่อนทันที 1 ค่า แล้วจึงส่งค่าผลลัพธ์ใหม่ไปคำนวณต่อในนิพจน์นั้นๆ
      2. Suffix (วางไว้ด้านหลัง เช่น x++): ส่งค่าปัจจุบันของ x ไปประมวลผลคำนวณในนิพจน์ก่อน แล้วจึงสั่งบวก/ลดค่าตัวแปร x เพิ่มขึ้นลับหลังในบรรทัดนั้น
    let x = 10;
let y = 2 + (++x); // x เพิ่มเป็น 11 ทันที, จากนั้น y = 2 + 11 จะได้ y = 13

let a = 10;
let b = 2 + (a++); // นำ a ปัจจุบัน (10) ไปคำนวณก่อน b = 2 + 10 จะได้ b = 12 จากนั้นตัวแปร a จึงขยับเพิ่มเป็น 11 ในระบบทีหลัง

    4.5 เครื่องหมายเปรียบเทียบ (Comparison Operators)

    ใช้ทดสอบความสัมพันธ์ของค่า 2 ค่า ผลลัพธ์ส่งค่าบูลีน true/false ออกมาเสมอ: * == (เท่ากับ - เปรียบเทียบเฉพาะค่าโดยอาจละเว้นความต่างชนิดข้อมูล), != (ไม่เท่ากับ) * > (มากกว่า), < (น้อยกว่า), >= (มากกว่าหรือเท่ากับ), <= (น้อยกว่าหรือเท่ากับ)

    [!NOTE] สำหรับข้อมูลชนิดข้อความ (String) จะอาศัยการเปรียบเทียบลำดับอักษรตามมาตรฐาน Unicode และมีความอ่อนไหวเรื่องขนาดตัวอักษร (Case-Sensitive) เช่น 'abcd' != 'ABCD' จะมีค่าเป็น true

    4.6 เครื่องหมายทางตรรกศาสตร์ (Logical Operators)

    ใช้เชื่อมหลายเงื่อนไข: * && (AND - และ): ผลลัพธ์จะเป็นจริง (true) ก็ต่อเมื่อ ทุกเงื่อนไข รอบเครื่องหมายเป็นจริงทั้งหมด * || (OR - หรือ): ผลลัพธ์จะเป็นจริง (true) ขอเพียงแค่มี อย่างน้อยหนึ่งเงื่อนไข รอบเครื่องหมายที่เป็นจริง * ! (NOT - ปฏิเสธ): สลับสถานะบูลีนเป็นตรงข้าม เช่น !true จะกลายเป็น false

    4.7 เครื่องหมายเปรียบเทียบแบบย่อ 3 ส่วน (Ternary Operator)

    ช่วยย่อคำสั่งเขียนตัดสินใจและคืนค่าเงื่อนไขโดยเขียนสั้นๆ ในแถวเดียว:

    // รูปแบบ: ตัวแปร = (เงื่อนไข) ? ค่าถ้าจริง : ค่าถ้าเท็จ;
let x = 20;
let result = (x % 2 === 0) ? "Even" : "Odd"; // จะได้ค่า result = "Even"

    4.8 การใช้เครื่องหมาย || กำหนดค่าเริ่มต้น (Falsy Short-circuiting)

    ใน JavaScript ข้อมูลจำพวก false, 0, "" (ข้อความว่าง), null, undefined, และ NaN จะเรียกว่า Falsy values (ค่าที่เสมือนว่าเป็นเท็จ) เราสามารถนำคณิตศาสตร์ตรรกะตัวเชื่อม || มาใช้อ้างอิงเพื่อเติมค่าเริ่มต้นให้กับตัวแปรยามที่เกิดสภาวะว่างเปล่าได้ง่ายๆ:

    let userSetting; // ปัจจุบันมีสถานะเป็น undefined (Falsy)
let themeColor = userSetting || "dark"; // หากฝั่งซ้ายเป็น Falsy ระบบจะโยนค่าเริ่มต้นฝั่งขวา "dark" ไปเก็บไว้แทน

    4.9 เทมเพลตสตริง (Template Literals และ Interpolation)

    เพื่อลดความรุงรังในการเชื่อมสายอักขระและค่าตัวแปรด้วยเครื่องหมายบวก (+) เรานิยมใช้เครื่องหมาย Backtick (`) ครอบข้อความ และระบุแทรกค่าตัวแปรหรือนิพจน์คณิตศาสตร์ลงไปตรงๆ ด้วยฟอร์แมต ${ตัวแปรหรือการคำนวณ}

    let name = "สมชาย";
let score = 95;
// แบบเดิม: console.log("นักเรียนชื่อ " + name + " สอบได้คะแนน " + score + " คะแนน");
// แบบใหม่ที่เรียบร้อยกว่า:
console.log(`นักเรียนชื่อ ${name} สอบได้คะแนน ${score} คะแนน`);

// สามารถคำนวณนิพจน์ภายในสัญลักษณ์ ${} ได้โดยตรง
let miles = 10;
console.log(`ระยะทาง ${miles} ไมล์ เทียบเท่ากับ ${miles * 1.6} กิโลเมตร`);

    5. การแปลงและตรวจสอบชนิดข้อมูลเบื้องต้น (Data Type Conversion)

    เพื่อแก้ปัญหากรณีตัวเลขติดอยู่ในรูปของข้อความ (String Number) แล้วนำมาบวกกันแบบผิดพลาด เราสามารถจัดระเบียบข้อมูลใหม่ด้วยฟังก์ชันเหล่านี้:

    1. parseInt(ข้อมูล): แปลงสตริงให้กลายเป็นตัวเลขจำนวนเต็มหลักสิบหลักหน่วยปกติ เช่น "123" -> 123
    2. parseFloat(ข้อมูล): แปลงสตริงให้กลายเป็นตัวเลขทศนิยม เช่น "120.25" -> 120.25
    3. Number.isInteger(ข้อมูล): ใช้เช็คว่าค่าตัวแปรนั้นเป็นจำนวนเต็มตัวจริงหรือไม่ คืนค่าเป็น true / false

    ความพิเศษในการคัดลอกถอดรหัสตัวเลข (Extraction Feature)

    ฟังก์ชัน parseInt() และ parseFloat() มีความสามารถพิเศษในการพยายามดึงตัดเลขที่อยู่ ส่วนหน้าสุด ของข้อความออโตเมติกจนกระทั่งไปปะทะตัวอักษร แต่หากตัวหน้าสุดเป็นอักษรทันทีจะคืนค่า NaN แทน:

    parseInt("100MB");        // ได้ผลลัพธ์เป็น 100
parseFloat("120.25GB");   // ได้ผลลัพธ์เป็น 120.25
parseInt("-90degree");    // ได้ผลลัพธ์เป็น -90
parseInt("ECMAScript8");  // ได้ผลลัพธ์เป็น NaN (เพราะตัวแรกสุดขึ้นต้นด้วยอักษรตัว E ไม่ใช่ตัวเลข)

    6. การรับข้อมูลผ่าน Console บนสภาพแวดล้อม Node.js

    ในการเขียนโปรแกรมแบบตอบโต้อินเตอร์แอคทีฟบนหน้าจอ Terminal คีย์เวิร์ดรับข้อมูลแบบ GUI บนเว็บเบราว์เซอร์จะไม่สามารถใช้งานได้ เราจึงต้องติดตั้งโมดูลอำนวยความสะดวกชื่อว่า prompt-sync เพิ่มเติมในโปรเจกต์

    วิธีการติดตั้ง

    เปิดแถบ Terminal ในโฟลเดอร์โปรเจกต์ของคุณแล้วเรียกใช้คำสั่งติดตั้งผ่าน npm:

    npm install prompt-sync

    รูปแบบการนำไปประยุกต์ใช้งานในโค้ด

    // ดึงโมดูลเข้ามาทำงาน
const prompt = require('prompt-sync')();

// รับข้อมูลจากคีย์บอร์ด (ค่าที่ได้กลับมาจะเป็นข้อมูลชนิด String เสมอ)
let num1 = prompt("ป้อนตัวเลขที่ 1: ");
let num2 = prompt("ป้อนตัวเลขที่ 2: ");

// จำเป็นต้องแปลงเป็นตัวเลขก่อนคำนวณผลบวก (+) เพื่อป้องกันสตริงเชื่อมกันเอง
let result = parseFloat(num1) + parseFloat(num2);

console.log(`ผลบวกรวมที่ได้คือ: ${result}`);

    💻 แบบฝึกหัดท้ายบทเรียน (Workshop)

    เป้าหมาย: สร้างโปรแกรมคอมพิวเตอร์คำนวณอายุและน้ำหนักดัชนีมวลกายอย่างง่ายผ่านการรับค่าทางคีย์บอร์ด

    ขั้นตอนปฏิบัติ: 1. ตรวจสอบว่าคุณได้ติดตั้งโมดูลด้วยคำสั่ง npm install prompt-sync ในโฟลเดอร์เรียบร้อยแล้ว 2. สร้างไฟล์โค้ดใหม่ชื่อ calculator.js 3. เขียนโค้ดตามแนวทางด้านล่างนี้ลงในไฟล์และทำการบันทึก:

    // ดึงโมดูล prompt-sync
const prompt = require('prompt-sync')();

console.log("=== โปรแกรมคำนวณน้ำหนัก BMI และคำนวณปีเกิด ===");

// 1. รับข้อมูลจากผู้ใช้งาน
let name = prompt("กรุณาระบุชื่อของคุณ: ");
let currentYear = prompt("กรุณาระบุปี ค.ศ. ปัจจุบัน (เช่น 2026): ");
let birthYear = prompt("กรุณาระบุปี ค.ศ. เกิดของคุณ: ");
let weight = prompt("ระบุน้ำหนักตัวของคุณ (กิโลกรัม): ");
let heightCm = prompt("ระบุส่วนสูงของคุณ (เซนติเมตร): ");

// 2. แปลงข้อมูลและคำนวณผลลัพธ์
let age = parseInt(currentYear) - parseInt(birthYear);

// คำนวณ BMI = น้ำหนัก (kg) / ส่วนสูงเมตรยกกำลังสอง (m^2)
let heightM = parseFloat(heightCm) / 100;
let bmi = parseFloat(weight) / (heightM ** 2);

// 3. แสดงผลลัพธ์โดยใช้ Template Literal
console.log("-----------------------------------------");
console.log(`สวัสดีคุณ ${name}`);
console.log(`ปัจจุบันคุณมีอายุประมาณ: ${age} ปี`);
console.log(`ค่าดัชนีมวลกาย (BMI) ของคุณคือ: ${bmi.toFixed(2)}`);
console.log("-----------------------------------------");
    1. เปิดหน้าต่าง Terminal ใน VS Code และพิมพ์สั่งรันโปรแกรม: bash node calculator.js
    2. ลองป้อนค่าต่างๆ เพื่อดูผลการประมวลผลและการปัดเศษทศนิยม BMI ด้วยคำสั่ง .toFixed(2)

    💡 ข้อมูลเพิ่มเติมสำหรับการเรียนรู้

    ในบทเรียนนี้ เราได้ทำความเข้าใจโครงสร้างเบื้องต้นของการประมวลผลทางสัญลักษณ์คณิตศาสตร์ ตัวแปร และชนิดข้อมูลหลักเรียบร้อยแล้ว แต่อย่างไรก็ตาม โค้ดยังไม่มีการตัดสินใจหรือการควบคุมทิศทางอย่างยืดหยุ่น เช่น หากผู้ใช้ป้อนน้ำหนักเป็น 0 หรือข้อความธรรมดา โปรแกรมก็จะคำนวณผลผิดพลาด ในบทถัดไปเรื่อง การควบคุมทิศทางของโปรแกรม (Control Flow - if/else, loops) เราจะมาไขข้อข้องใจเหล่านี้และเขียนโปรแกรมที่มีความฉลาดรอบคอบยิ่งขึ้นไปอีกระดับ!
