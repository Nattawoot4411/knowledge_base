    บทที่ 3: ประเภทข้อมูล (Data Types)

    ในการเขียนโปรแกรม คอมพิวเตอร์จำเป็นต้องรู้ว่าข้อมูลที่เก็บอยู่ในตัวแปรนั้นมีประเภทใด เพื่อการคำนวณและประมวลผลที่ถูกต้อง ใน JavaScript มีชนิดข้อมูลพื้นฐานที่ใช้บ่อยดังนี้:

    1. ข้อมูลชนิดต่างๆ

    • Boolean: ค่าความจริง มีเพียง 2 ค่า คือ true (จริง) หรือ false (เท็จ)
    • Number: ค่าตัวเลข (ทศนิยมหรือจำนวนเต็มก็ได้) เช่น 25, 3.14
    • String: ข้อความหรือตัวอักษร ต้องครอบด้วยเครื่องหมายอัญประกาศคู่ ("...") หรือเดี่ยว ('...') เช่น "Hello"
    • Null: ค่าว่างเปล่าแบบตั้งใจประกาศให้รู้ว่าขณะนี้ไม่มีค่าใดๆ บรรจุอยู่
    • Undefined: ตัวแปรที่ประกาศขึ้นแล้วแต่ยังไม่ได้มอบค่าตั้งต้นให้
    let isLearning = true;       // Boolean
let age = 25;                // Number
let greeting = "Hello";      // String
let emptyValue = null;       // Null
let notDefined;              // Undefined (มีค่าเป็น undefined เสมอ)
