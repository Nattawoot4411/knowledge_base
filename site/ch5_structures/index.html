    บทที่ 5: โครงสร้างข้อมูล (Array, Object และ JSON)

    เมื่อโปรแกรมมีความซับซ้อนมากขึ้น การใช้ตัวแปรปกติเพื่อเก็บข้อมูลทีละค่าจะสร้างความยุ่งยากอย่างมหาศาล ตัวอย่างเช่น หากต้องการเก็บข้อมูลตัวเลข 10 จำนวน การสร้างตัวแปร n1 ถึง n10 จะทำให้โค้ดซ้ำซ้อนและขาดความยืดหยุ่น ภาษาจาวาสคริปต์จึงมีโครงสร้างข้อมูลเพื่อแก้ปัญหานี้ ได้แก่ "อาร์เรย์" (Array) สำหรับจัดการชุดข้อมูลที่เป็นลำดับต่อเนื่อง และ "ออบเจ็กต์" (Object) สำหรับจัดการข้อมูลที่มีลักษณะเป็นคุณสมบัติ (Property) นอกจากนี้ เมื่อต้องนำข้อมูลเหล่านี้ไปแลกเปลี่ยนข้ามระบบปฏิบัติการหรือภาษาคอมพิวเตอร์ที่แตกต่างกัน เราจำเป็นต้องพึ่งพารูปแบบข้อมูลมาตรฐานที่เรียกว่า JSON บทเรียนนี้จะเจาะลึกโครงสร้างข้อมูลทั้งสามรูปแบบนี้อย่างละเอียดครบถ้วน

    จุดประสงค์การเรียนรู้

    เมื่อศึกษาบทเรียนนี้จบแล้ว ผู้เรียนควรมีความสามารถดังนี้: * เข้าใจโครงสร้าง การสร้าง และการอ้างอิงลำดับดัชนี (Index) ของอาร์เรย์ได้อย่างถูกต้อง * ประยุกต์ใช้คำสั่งวนลูปทุกรูปแบบ (for, for-in, for-of, forEach) กับอาร์เรย์และสตริงได้ * เลือกใช้งานเมธอด (Method) ทั้ง 15 คำสั่งเพื่อจัดการ ดัดแปลง และค้นหาข้อมูลในอาร์เรย์ได้อย่างมีประสิทธิภาพ * เข้าใจกลไกของอาร์เรย์แบบ 2 มิติ (Array of Array) และการเข้าถึงสมาชิกย่อย * อธิบายความแตกต่างระหว่างอาร์เรย์และออบเจ็กต์ พร้อมทั้งสร้างและจัดการพร็อพเพอร์ตี้ของออบเจ็กต์ได้ * เข้าใจการสร้างเมธอดในออบเจ็กต์ และการใช้งานคีย์เวิร์ด this * อธิบายกฎเกณฑ์ของออบเจ็กต์แบบ JSON และสามารถแปลงข้อมูลกลับไปมาด้วย JSON.stringify() และ JSON.parse() ได้

    1. ลักษณะพื้นฐานและการสร้างอาร์เรย์ (Array Basics)

    • หลักการสำคัญ: อาร์เรย์ (Array) คือชุดข้อมูลที่รวบรวมข้อมูลย่อยๆ (Element/สมาชิก) มาเก็บไว้ภายใต้ตัวแปรชื่อเดียวกัน โดยสมาชิกแต่ละตัวจะมีเลขลำดับกำกับที่เรียกว่า ดัชนี (Index หรือ Subscript)
      • ดัชนีของอาร์เรย์จะ เริ่มต้นจาก 0 เสมอ ไปจนสิ้นสุดที่จำนวนสมาชิกตัวสุดท้าย
      • จาวาสคริปต์อนุญาตให้อาร์เรย์หนึ่งชุด เก็บข้อมูลต่างชนิดกันได้ (เช่น ตัวเลข สตริง บูลีน อยู่รวมกันได้)
      • การสร้างอาร์เรย์ทำได้ 2 วิธีหลัก คือ การใช้วงเล็บเหลี่ยม [ ] (แนะนำ) และ การใช้ออบเจ็กต์ new Array()
    • รายละเอียดเชิงลึกและประเด็นที่ควรรู้: กรณีใช้ new Array(): หากกำหนดค่าเริ่มต้นเป็นเลขจำนวนเต็มเพียงตัวเดียว เช่น new Array(5) โปรแกรมจะมองว่านั่นคือ "การจองพื้นที่ขนาด 5 ช่อง" (สมาชิกทุกตัวจะเป็น undefined) แต่หากใส่เลขทศนิยม เช่น new Array(7.5) จะเกิดข้อผิดพลาด (Error) ทันที แต่ถ้ากำหนดค่าตั้งแต่ 2 ตัวขึ้นไป หรือเป็นสตริง เช่น new Array('Apple') หรือ new Array(10, 20) จะถูกมองว่าเป็นข้อมูลสมาชิกตามปกติ

    ตัวอย่างประกอบ:

    // วิธีที่ 1: ใช้เครื่องหมาย []
let oddNumbers = [1, 3, 5, 7, 9];
let mixedData = [1, true, "three"]; // เก็บข้อมูลต่างชนิดกันได้
let emptyArray = []; // อาร์เรย์ว่าง

// วิธีที่ 2: ใช้ new Array()
let browsers = new Array('Chrome', 'Edge', 'Firefox', 'Safari');
let slots = new Array(5); // ขนาด 5 ช่อง (ทุกช่องเป็น undefined)

console.log("oddNumbers:", oddNumbers);
console.log("mixedData:", mixedData);
console.log("browsers:", browsers);
console.log("slots length:", slots.length);

    2. การเข้าถึงและจัดการสมาชิกของอาร์เรย์

    • หลักการสำคัญ: การอ่านค่าหรือกำหนดค่าใหม่ให้กับสมาชิกอาร์เรย์ ต้องอ้างอิงผ่านชื่อตัวแปรตามด้วยเครื่องหมายก้ามปูและเลขดัชนี เช่น arrayName[index]
    • รายละเอียดเชิงลึกและประเด็นที่ควรรู้:
      • หากเราอ้างถึงดัชนีที่ไม่มีอยู่จริง โปรแกรมจะคืนค่าเป็น undefined โดยไม่ฟ้อง Error
      • การกระโดดข้ามลำดับดัชนี: หากอาร์เรย์มีสมาชิกดัชนี 0, 1, 2 แล้วเราไปกำหนดค่าให้ดัชนีที่ 7 ทันที โปรแกรมจะขยายขนาดอาร์เรย์ให้ถึงดัชนี 7 อัตโนมัติ โดยช่องว่างที่ถูกกระโดดข้าม (ดัชนี 3 ถึง 6) จะมีค่าเป็น undefined
      • การใช้คีย์เวิร์ด in: เราสามารถตรวจสอบว่ามี "ลำดับดัชนี" นั้นๆ อยู่ในอาร์เรย์หรือไม่ โดยใช้คำสั่ง index in arrayName (คืนค่าเป็น true/false)

    ตัวอย่างประกอบ:

    let browsers = new Array('Chrome', 'IE', 'Firefox', 'Safari');

console.log(browsers[0]); // พิมพ์ Chrome
console.log(browsers[4]); // พิมพ์ undefined เพราะมีแค่ดัชนี 0 ถึง 3

browsers[1] = 'Edge';     // แก้ไข IE เป็น Edge
browsers[7] = 'Netscape'; // เพิ่มข้ามลำดับ ดัชนี 4, 5, 6 จะเป็น undefined ทันที
console.log("หลังแก้ไขและเพิ่ม:", browsers);

// การตรวจสอบดัชนีด้วยคำสั่ง in
let arr = [10, 20, 30]; // ดัชนี 0, 1, 2
console.log("มีดัชนี 0 ในอาร์เรย์หรือไม่: " + (0 in arr));  // true
console.log("มีดัชนี 3 ในอาร์เรย์หรือไม่: " + (3 in arr));  // false

    3. การวนลูปเพื่อเข้าถึงสมาชิกในอาร์เรย์

    • หลักการสำคัญ: เมื่อมีข้อมูลจำนวนมาก การดึงข้อมูลทีละตัวแบบระบุดัชนีจึงไม่สะดวก เราจำเป็นต้องนำโครงสร้างการวนลูปมาประยุกต์ใช้ ซึ่งจาวาสคริปต์มีรูปแบบการวนลูปสำหรับอาร์เรย์ที่หลากหลายมาก
    คำสั่งวนลูป ลักษณะการทำงาน จุดเด่น / ข้อสังเกต
    for นำตัวแปรนับรอบ (มักใช้ i) ไปใช้เป็นลำดับดัชนี ต้องใช้ length เพื่อกำหนดเงื่อนไขหยุดลูป เหมาะกับการอ้างอิงตำแหน่งชัดเจน
    for...in ดึง "เลขลำดับดัชนี (Index)" ออกมาใส่ตัวแปรให้โดยอัตโนมัติ ไม่ต้องตั้งค่าตัวแปรนับรอบเอง เริ่มตั้งแต่ 0 ไปจนดัชนีสุดท้าย
    for...of เข้าถึง "ข้อมูล (Value)" โดยตรง ไม่ต้องพึ่งพาดัชนี โค้ดกระชับ อ่านง่าย และใช้ได้กับสตริงดึงอักษรทีละตัวได้
    forEach() เป็นเมธอดพิเศษของอาร์เรย์ ต้องรับพารามิเตอร์เป็น Callback ส่งข้อมูลสมาชิก (element) และดัชนี (index) เข้าไปในฟังก์ชันทีละรอบ

    ตัวอย่างประกอบ:

    let nums = [10, 20, 30, 40, 50];

// 1. ใช้ for แบบปกติ
for (let i = 0; i < nums.length; i++) {
    console.log("For ปกติ: " + nums[i]);
}

// 2. ใช้ for...in (ได้ Index มา)
for (let i in nums) {
    console.log("For-in ดัชนีที่ " + i + ": " + nums[i]);
}

// 3. ใช้ for...of (ได้ Value มา)
for (let value of nums) {
    console.log("For-of ข้อมูล: " + value);
}

// การประยุกต์ใช้ for-of กับสตริง
let str = "JS";
for (let s of str) {
    console.log("ตัวอักษร: " + s); // พิมพ์ J, S ทีละบรรทัด
}

// 4. ใช้ forEach() พร้อม Callback
let browsersList = ['Chrome', 'Edge', 'Firefox', 'Safari'];
browsersList.forEach(function(element, index) {
    console.log((index + 1) + ". " + element);
});

    4. เมธอดของอาร์เรย์ (Array Methods)

    • หลักการสำคัญ: อาร์เรย์ในจาวาสคริปต์มีเครื่องมือสำเร็จรูป (Method) ที่ช่วยให้เราจัดการ ดัดแปลง หรือค้นหาข้อมูลได้อย่างรวดเร็ว
    กลุ่มการใช้งาน คำสั่ง (Method) หน้าที่และลักษณะการทำงาน
    ให้ข้อมูล/ค้นหา length (Property)
    includes(สมาชิก)
    indexOf(สมาชิก)
    lastIndexOf(สมาชิก)    		 นับจำนวนสมาชิกทั้งหมด
    ตรวจสอบว่ามีข้อมูลนั้นอยู่หรือไม่ (true/false)
    ค้นหาตำแหน่งดัชนีแรกที่พบ (ไม่พบคืน -1)
    ค้นหาตำแหน่งดัชนีสุดท้ายจากหลังมาหน้า
    เพิ่ม/ลบ (ท้ายอาร์เรย์) push(สมาชิก, ...)
    pop()    		 เพิ่มสมาชิกเข้าไปต่อท้ายสุด
    ลบและคืนค่าสมาชิกตัวสุดท้ายออก 1 ตัว
    เพิ่ม/ลบ (หน้าอาร์เรย์) unshift(สมาชิก, ...)
    shift()    		 เพิ่มสมาชิกเข้าไปหน้าสุด (ดัชนี 0)
    ลบและคืนค่าสมาชิกตัวแรกสุดออก 1 ตัว
    จัดการโครงสร้าง join('ตัวคั่น')
    concat(อาร์เรย์อื่น)
    fill(ข้อมูล, ...)    		 แปลงสมาชิกทั้งหมดเป็นสตริงคั่นด้วยตัวคั่น
    เชื่อมต่ออาร์เรย์เพื่อสร้างอาร์เรย์ใหม่
    เติมข้อมูลทับลงไปในสมาชิกทุกตัวตามช่วงที่กำหนด
    เรียงลำดับ reverse()
    sort()    		 กลับลำดับข้อมูลจากหลังมาหน้า
    เรียงข้อมูล A-Z (ควรระวังหากใช้เรียงตัวเลขตรงๆ)
    คัดลอก/ตัดต่อ slice(start, end)
    splice(start, del, ...)    		 คัดลอกสมาชิกบางส่วนออกมา (ต้นฉบับไม่เปลี่ยน)
    ตัดสมาชิกเดิมออกและแทรกข้อมูลใหม่ลงไป (ต้นฉบับเปลี่ยน)

    ตัวอย่างประกอบ:

    let arr1 = ['หมู', 'หมา', 'กา', 'ไก่'];
arr1.sort();    // ได้ ['กา', 'ไก่', 'หมา', 'หมู'] (ตามลำดับพยัญชนะ)
arr1.reverse(); // ได้ ['หมู', 'หมา', 'ไก่', 'กา']
console.log("arr1:", arr1);

let nums = [1, 2, 3, 4];
nums.unshift(0); // [0, 1, 2, 3, 4]
let x = nums.pop(); // x = 4, nums = [0, 1, 2, 3]
console.log("nums:", nums, "ค่าที่ pop ออกมา:", x);

// ตัวอย่าง Slice (คัดลอก)
let data = [10, 20, 30, 40, 50];
let part1 = data.slice(2, 4); // คัดลอกดัชนี 2 ถึง 3 (ไม่รวม 4) -> ได้ [30, 40]
console.log("part1 (slice):", part1);

// ตัวอย่าง Splice (ตัดออก)
let part2 = data.splice(1, 3); // เริ่มตัดที่ดัชนี 1 จำนวน 3 ตัว -> ได้ [20, 30, 40]
console.log("part2 (splice):", part2);
console.log("data ที่เหลืออยู่:", data); // เหลือแค่ [10, 50]

    5. การส่งอาร์เรย์เข้าและออกจากฟังก์ชัน

    • หลักการสำคัญ: อาร์เรย์เป็นชุดข้อมูลที่สามารถถูกส่งผ่านไปให้ฟังก์ชันประมวลผล (ในฐานะพารามิเตอร์) และฟังก์ชันก็สามารถประมวลผลลัพธ์ที่ซับซ้อนแล้วส่งข้อมูลกลับออกมาเป็นชุดอาร์เรย์ได้เช่นกัน (ในฐานะค่า Return)

    ตัวอย่างประกอบ:

    // ฟังก์ชันรับพารามิเตอร์เป็นอาร์เรย์
function summation(dataArray) {
    let sum = 0;
    for (let n of dataArray) {
        sum += n;
    }
    return sum;
}
let total = summation([1, 3, 5, 7]); // ส่งอาร์เรย์เข้าไป
console.log("ผลรวม:", total); // พิมพ์ 16

// ฟังก์ชันส่งค่ากลับเป็นอาร์เรย์
function getRandomNumbers() {
    let arr = new Array(5);
    for (let i = 0; i < arr.length; i++) {
        arr[i] = parseInt(Math.random() * 100);
    }
    return arr; // ส่งอาร์เรย์กลับออกไป
}
console.log("สุ่มตัวเลข 5 ตัว:", getRandomNumbers());

    6. อาร์เรย์แบบ 2 มิติ (Multidimensional Array)

    • หลักการสำคัญ: สมาชิกของอาร์เรย์หนึ่งๆ สามารถมีค่าเป็น "อาร์เรย์อีกชุดหนึ่ง" ได้ โครงสร้างที่ซ้อนกันนี้เรียกว่า อาร์เรย์ 2 มิติ (หรือ Array of Array) เหมาะกับการเก็บข้อมูลประเภทตาราง แถว คอลัมน์ หรือพิกัด
    • รายละเอียดเชิงลึกและประเด็นที่ควรรู้:
      • การเข้าถึงข้อมูล: ใช้วงเล็บเหลี่ยม 2 ชุดซ้อนกัน array[ดัชนีชั้นนอก][ดัชนีชั้นใน] (เปรียบเสมือน array[แถว][คอลัมน์])
      • การหาขนาด: ใช้ array.length (ได้จำนวนแถว) และ array[index].length (ได้จำนวนคอลัมน์ของแถวนั้นๆ)
      • การวนลูปอ่านข้อมูล: จำเป็นต้องใช้การวนลูปซ้อนลูป (Nested Loops)

    ตัวอย่างประกอบ:

    let colors = [
    ['red', 'green', 'blue'],   // แถวที่ 0
    ['black', 'white']          // แถวที่ 1
];

console.log(colors[1][0]); // พิมพ์ black (แถว 1 คอลัมน์ 0)
console.log("จำนวนแถว:", colors.length); // พิมพ์ 2
console.log("จำนวนคอลัมน์แถว 0:", colors[0].length); // พิมพ์ 3

// การเพิ่มข้อมูลเข้าไปในอาร์เรย์ย่อย
colors[1].push('yellow'); 
console.log("แถว 1 หลังเพิ่มสีเหลือง:", colors[1]);

// การวนลูปดึงข้อมูล 2 มิติด้วย for...of
for (let row of colors) {
    for (let col of row) {
        console.log("สี: " + col); // พิมพ์ค่าสีออกมาทีละสี
    }
}

    7. ออบเจ็กต์ของจาวาสคริปต์ (JavaScript Objects)

    • หลักการสำคัญ: โครงสร้างข้อมูลแบบ ออบเจ็กต์ (Object) ใช้จัดโครงสร้างข้อมูลโดยมีชื่อที่สื่อความหมาย (Key) แทนการใช้ดัชนีตัวเลข โดยองค์ประกอบสำคัญของออบเจ็กต์มี 2 อย่างคือ:
      • พร็อพเพอร์ตี้ (Property): การเก็บข้อมูลในลักษณะคู่ของ key (ชื่อคุณสมบัติ) และ value (ค่าข้อมูล)
      • เมธอด (Method): พฤติกรรมหรือฟังก์ชันการทำงานที่แนบอยู่กับออบเจ็กต์
    • รายละเอียดเชิงลึก: การสร้างออบเจ็กต์พื้นฐาน นิยมใช้วงเล็บปีกกา { } (Object Literal) หรือคำสั่ง new Object() โดยค่า Value สามารถเป็นชนิดข้อมูลใดก็ได้ ทั้งตัวเลข สตริง บูลีน อาร์เรย์ วันที่ หรือเป็นออบเจ็กต์ซ้อนอยู่ภายใน

    ตัวอย่างประกอบ:

    // การสร้างออบเจ็กต์พร้อมข้อมูล (แบบ Object Literal)
let rectangle = {
    width: 10,
    height: 20
};
console.log("Rectangle Width:", rectangle.width);

// ข้อมูลที่มีความซับซ้อน (มีอาร์เรย์และออบเจ็กต์ซ้อนอยู่ภายใน)
let language = {
    name: 'JavaScript',
    born: new Date(1995, 10, 1),
    developer: ['Brendan Eich', 'ECMA'],
    price: undefined,
    browserSupport: {
        Microsoft: 'Edge',
        Google: 'Chrome'
    }
};
console.log("Language Name:", language.name);
console.log("Developer Team:", language.developer[1]);
console.log("Chrome support status:", language.browserSupport.Google);

    8. การเข้าถึงและการกำหนดค่าให้พร็อพเพอร์ตี้

    • หลักการสำคัญ: การอ่านค่า หรือเปลี่ยนแปลงค่าภายในออบเจ็กต์สามารถทำได้ 2 รูปแบบหลัก
    • รายละเอียดเชิงลึกและประเด็นที่ควรรู้:
      • แบบจุด (Dot Notation): เช่น object.propertyName เป็นวิธีที่สั้น สะดวก และนิยมใช้มากที่สุด
      • แบบวงเล็บ (Bracket Notation): เช่น object['propertyName'] ต้องใส่ชื่อพร็อพเพอร์ตี้ไว้ในเครื่องหมายคำพูดเสมอ มีประโยชน์มากเมื่อชื่อพร็อพเพอร์ตี้ถูกเก็บอยู่ใน "ตัวแปร" ชนิดข้อความ
      • เราสามารถเพิ่มพร็อพเพอร์ตี้ใหม่ให้กับออบเจ็กต์ในภายหลังได้ตลอดเวลา หรือใช้คำสั่ง Object.assign() เพื่อคัดลอกพร็อพเพอร์ตี้หลายๆ ตัวพร้อมกันได้

    ตัวอย่างประกอบ:

    let person = { name: "John", age: 30 };

// 1. เข้าถึงด้วย Dot Notation
console.log(person.name); // John
person.age = 31; // แก้ไขค่า

// 2. เข้าถึงด้วย Bracket Notation
console.log(person['age']); // 31
let propToAccess = 'name';
console.log(person[propToAccess]); // ใช้ตัวแปรเข้าถึงได้

// การเพิ่มพร็อพเพอร์ตี้ใหม่ในภายหลัง
person.country = "USA"; 

// การเพิ่มหลายพร็อพเพอร์ตี้พร้อมกันด้วย Object.assign()
Object.assign(person, {
    job: "Developer",
    salary: 50000
});
console.log("ออบเจ็กต์หลังอัปเดต:", person);

    9. การเข้าถึงออบเจ็กต์ด้วยลูปและคำสั่งพิเศษ

    • หลักการสำคัญ: เนื่องจากออบเจ็กต์ไม่มีลำดับดัชนีแบบอาร์เรย์ การวนลูปดึงคุณสมบัติทั้งหมดของออบเจ็กต์ออกใช้ จึงต้องใช้คำสั่งเฉพาะตัว ดังนี้
    คำสั่ง / ไวยากรณ์ ลักษณะการทำงาน
    for...in วนลูปดึง "ชื่อคีย์ (Key)" ออกมาทีละรอบ (ต้องใช้ Bracket Notation เพื่อดึงค่า Value)
    Object.keys(ออบเจ็กต์) ดึงคีย์ทั้งหมดออกมาสร้างเป็น "อาร์เรย์ของชื่อคีย์" เพื่อนำไปประยุกต์ใช้กับลูป for...of ต่อได้
    with (ออบเจ็กต์) ไวยากรณ์เก่า (ไม่แนะนำให้ใช้ในโค้ดใหม่) ช่วยให้อ้างถึงคีย์ได้ตรงๆ โดยไม่ต้องพิมพ์ชื่อออบเจ็กต์นำหน้า

    ตัวอย่างประกอบ:

    let rectangle = { width: 10, height: 20 };

// การใช้ for...in
for (let p in rectangle) {
    // ต้องใช้แบบวงเล็บเพราะ p เป็นตัวแปรเก็บชื่อคีย์
    console.log(p + " มีค่า: " + rectangle[p]); 
}

// การใช้ Object.keys() ร่วมกับ for...of
let keys = Object.keys(rectangle);
for (let p of keys) {
    console.log("คีย์ " + p + " มีค่า: " + rectangle[p]);
}

    10. เมธอดของออบเจ็กต์ (Object Methods)

    • หลักการสำคัญ: หากนำฟังก์ชันไปกำหนดค่าให้กับพร็อพเพอร์ตี้ของออบเจ็กต์ จะเรียกว่า "เมธอด" ซึ่งเปรียบเสมือนพฤติกรรมหรือฟังก์ชันเฉพาะตัวของออบเจ็กต์นั้น
    • รายละเอียดเชิงลึกและประเด็นที่ควรรู้:
      • รูปแบบการเขียน: เขียนแบบฟังก์ชันปกติ methodName: function() { ... } หรือจะเขียนแบบย่อเป็น methodName() { ... } ก็ได้
      • คีย์เวิร์ด this: จำเป็นต้องใช้ this นำหน้าเสมอยามที่ฟังก์ชันต้องการเรียกดูพร็อพเพอร์ตี้อื่นๆ ภายในออบเจ็กต์เดียวกัน (เช่น this.radius หมายถึงค่ารัศมีในออบเจ็กต์ปัจจุบัน)
      • ข้อควรระวังเกี่ยวกับ Arrow Function: หากเขียนเมธอดด้วย Arrow Function this จะชี้ออกไปที่สโคปภายนอกออบเจ็กต์ หากต้องการอ้างอิงคุณสมบัติภายในออบเจ็กต์ ต้องใช้ "ชื่อออบเจ็กต์" ตรงๆ แทนการใช้ this

    ตัวอย่างประกอบ:

    let circle = {
    radius: 10,
    // แบบฟังก์ชันปกติ
    getArea: function(pi=3.14) {
        return pi * (this.radius ** 2); // ใช้ this อ้างถึงพร็อพเพอร์ตี้ในตัวมันเอง
    },
    // แบบฟังก์ชันย่อ (Shorthand)
    getPerimeter(pi=3.14) {
        return 2 * pi * this.radius;
    }
};

console.log("Area:", circle.getArea());
console.log("Perimeter:", circle.getPerimeter());

// การเพิ่มเมธอดภายหลังด้วย Arrow Function
circle.sphereVolume = (pi=3.14) => {
    // ห้ามใช้ this.radius เพราะนี่คือ Arrow Function
    // ต้องอ้างชื่อออบเจ็กต์โดยตรง
    return (4/3) * pi * (circle.radius ** 3); 
};
console.log("Volume:", circle.sphereVolume());

    11. ออบเจ็กต์แบบ JSON (JavaScript Object Notation)

    • หลักการสำคัญ: JSON คือรูปแบบข้อความสตริงมาตรฐานสากล (Text-based Data Format) ที่ใช้แลกเปลี่ยนข้อมูลข้ามระบบปฏิบัติการและภาษาคอมพิวเตอร์ที่ต่างกัน โดยมีโครงสร้างเลียนแบบคู่ Key/Value ของจาวาสคริปต์
    • กฎเกณฑ์ที่เข้มงวดของ JSON:
      • คีย์และสตริงข้อมูล: ต้องถูกครอบด้วยเครื่องหมายอัญประกาศคู่ (" ") เท่านั้น ห้ามใช้ Single Quote (' ') หรือ Backtick (`) เด็ดขาด
      • ข้อมูลที่รองรับ (Value): สตริง, ตัวเลข, บูลีน, อาร์เรย์, ออบเจ็กต์ และ null
      • สิ่งต้องห้าม: ห้ามมีฟังก์ชัน (Method), ห้ามใช้ค่า undefined, ห้ามใช้ค่า NaN

    ตัวอย่างประกอบ:

    // สตริง JSON ที่ถูกต้องตามหลักการ 
// (สังเกตเครื่องหมาย " " รอบคีย์และข้อมูลสตริง)
let jsonStr = '{ "name": "Product 1", "price": 500, "inStock": true, "images": ["pic1.jpg", "pic2.jpg"] }';

// แปลง JSON สตริงไปใช้งานในฐานะ JS Object
let productObj = JSON.parse(jsonStr);
console.log("ชื่อสินค้าจาก JSON:", productObj.name);
console.log("รูปแรก:", productObj.images[0]);

    12. การแปลงข้อมูลระหว่าง Object และ JSON

    • หลักการสำคัญ: จาวาสคริปต์มีเครื่องมือสำเร็จรูปสำหรับแปลงข้อมูลกลับไปกลับมาระหว่างออบเจ็กต์ในหน่วยความจำ กับข้อมูลประเภทสตริง JSON คือ JSON.stringify() และ JSON.parse()

    คำสั่ง (Method) หน้าที่การทำงาน ข้อสังเกตเมื่อใช้งาน
    JSON.stringify(object) แปลงจาก Object ให้กลายเป็นสตริง JSON พร็อพเพอร์ตี้ที่ไม่ตรงตามกฎ (ฟังก์ชัน หรือ undefined) จะถูก ตัดทิ้ง อัตโนมัติ
    JSON.parse(jsonString) แปลงสตริง JSON ให้กลับมาเป็นออบเจ็กต์ สตริงต้นทางจะต้องถูกต้องตามหลักไวยากรณ์ JSON ทุกประการ มิฉะนั้นจะเกิด Error

    ตัวอย่างประกอบ:

    // สร้าง JS Object ที่มีฟังก์ชันและค่า undefined ปะปนอยู่
let circleObj = {
    "radius": 10,
    "color": "yellow",
    "name": undefined, // ผิดกฎ JSON (จะถูกตัดทิ้ง)
    getArea() {        // ผิดกฎ JSON (จะถูกตัดทิ้ง)
        return 3.14 * (this.radius ** 2);
    }
};

// 1. แปลง Object -> JSON String
let circleJsonStr = JSON.stringify(circleObj);
console.log("JSON Stringที่ได้:", circleJsonStr); 
// ผลลัพธ์: '{"radius":10,"color":"yellow"}' 

// 2. แปลง JSON String -> Object
let rawData = '{ "user": "John", "score": 95 }';
let parsedObject = JSON.parse(rawData);
console.log("ผู้ใช้ออบเจ็กต์:", parsedObject.user, "คะแนน:", parsedObject.score);

    สรุปบทเรียน

    ข้อมูลในแอปพลิเคชันยุคใหม่แทบทั้งหมดถูกจัดเก็บและประมวลผลผ่านโครงสร้างพื้นฐานสองรูปแบบ คือ อาร์เรย์ ที่เก่งด้านการจัดการข้อมูลเป็นลำดับต่อเนื่อง ผ่านระบบตัวเลขดัชนีพร้อมเมธอดอำนวยความสะดวกมากมาย และ ออบเจ็กต์ ที่เน้นการจัดโครงสร้างเชิงคุณสมบัติและพฤติกรรมผ่านการกำหนด Key/Value และการสร้าง Method การเข้าใจคีย์เวิร์ด this คือหัวใจของการเขียนออบเจ็กต์ให้ทำงานได้สมบูรณ์ และเมื่อระบบต้องเชื่อมต่อกับโลกภายนอก การทำความเข้าใจข้อจำกัดอันเข้มงวดของรูปแบบข้อมูล JSON จะช่วยป้องกันข้อผิดพลาดในการแปลงและส่งผ่านข้อมูลข้ามแพลตฟอร์มได้อย่างราบรื่น

    ❓ คำถามทบทวน (Review Questions)

    คลิกที่การ์ดคำถามด้านล่างเพื่อแสดงเฉลยคำตอบของคำถามแต่ละข้อ:

    1. การใช้คำสั่ง new Array(10.5) แตกต่างจาก new Array(10) อย่างไรในแง่ของผลลัพธ์?

      ดูเฉลยคำตอบ
      new Array(10) คือการจองขนาดพื้นที่ในหน่วยความจำสำหรับอาร์เรย์จำนวน 10 ช่อง (โดยค่าเริ่มต้นในแต่ละช่องจะเป็น undefined) ในขณะที่ new Array(10.5) จะส่งผลให้ระบบเกิดข้อผิดพลาด Error (RangeError: Invalid array length) ทันที เนื่องจากดัชนีขนาดของอาร์เรย์ต้องเป็นเลขจำนวนเต็มเท่านั้น

    2. คำสั่ง index in arrayName ใช้สำหรับตรวจสอบสิ่งใด และให้ผลลัพธ์เป็นข้อมูลประเภทใด?

      ดูเฉลยคำตอบ
      ใช้สำหรับตรวจสอบว่ามี "ลำดับดัชนี (Index)" หรือตำแหน่งช่องนั้นๆ อยู่จริงในอาร์เรย์หรือไม่ โดยให้ผลลัพธ์กลับมาเป็นข้อมูลประเภทบูลีน (true หรือ false)

    3. ลูป for...in และลูป for...of มีจุดประสงค์การทำงานกับอาร์เรย์แตกต่างกันอย่างไร?

      ดูเฉลยคำตอบ
      ลูป for...in จะดึง **"เลขตำแหน่งดัชนี (Index)"** ของสมาชิกอาร์เรย์ออกมาทีละตำแหน่ง ในขณะที่ลูป for...of จะดึง **"ค่าข้อมูล (Value)"** ของสมาชิกแต่ละช่องออกมาทำงานโดยตรงเลย

    4. หากต้องการลบข้อมูลออกจากตรงกลางอาร์เรย์ และนำข้อมูลใหม่แทรกลงไปในจุดที่ลบแทน ควรใช้เมธอดใด?

      ดูเฉลยคำตอบ
      ควรใช้เมธอด splice(ตำแหน่งเริ่มต้น, จำนวนตัวที่จะลบ, ข้อมูลใหม่ที่จะแทรก, ...)

    5. เพราะเหตุใดการเรียงลำดับชุดตัวเลขเช่น [20, 5, 100] ด้วยเมธอด sort() จึงอาจให้ผลลัพธ์ที่ไม่ถูกต้อง?

      ดูเฉลยคำตอบ
      เนื่องจากเมธอด sort() โดยค่าเริ่มต้นจะทำการเรียงลำดับสมาชิกในรูปแบบของข้อความ (String/Unicode) ทำให้อักษร 1 นำหน้าอักษร 2 ส่งผลให้เลข 100 มาก่อน 20 (ผลลัพธ์เป็น [100, 20, 5] หรือ [100, 5, 20] ขึ้นกับการเทียบค่าสตริง) หากต้องการเรียงลำดับตัวเลขที่ถูกต้อง จำเป็นต้องส่งฟังก์ชันเปรียบเทียบ (Compare Function) เข้าไปกำกับด้วย

    6. ในอาร์เรย์ 2 มิติ คำสั่ง array[0].length หมายถึงการตรวจสอบค่าความยาวของสิ่งใด?

      ดูเฉลยคำตอบ
      หมายถึงการตรวจสอบ จำนวนสมาชิก (จำนวนคอลัมน์) ที่อยู่ในอาร์เรย์ย่อยแถวที่ 0 (แถวแรก)

    7. หากต้องการเข้าถึงค่าในออบเจ็กต์ แต่ชื่อพร็อพเพอร์ตี้นั้นถูกเก็บอยู่ในตัวแปรชื่อ propKey เราจำเป็นต้องใช้ไวยากรณ์แบบใด?

      ดูเฉลยคำตอบ
      ต้องใช้ไวยากรณ์แบบวงเล็บก้ามปู (Bracket Notation) นั่นคือ objectName[propKey] (โดยไม่มีการใส่เครื่องหมายคำพูดครอบตัวแปร)

    8. เมื่อเราสร้างเมธอดในออบเจ็กต์ด้วยฟังก์ชันปกติ การใช้คีย์เวิร์ด this ภายในเมธอดนั้นจะหมายถึงสิ่งใด?

      ดูเฉลยคำตอบ
      คีย์เวิร์ด this จะหมายถึง ตัวออบเจ็กต์ปัจจุบัน (ออบเจ็กต์ที่เป็นเจ้าของเมธอดนั้นๆ) ช่วยให้เราอ้างอิงและดึงพร็อพเพอร์ตี้อื่นๆ ที่อยู่ในออบเจ็กต์เดียวกันมาใช้งานได้

    9. กฎระเบียบข้อใดของออบเจ็กต์แบบ JSON ที่เข้มงวดกว่าการสร้างออบเจ็กต์แบบปกติในจาวาสคริปต์? ยกตัวอย่างมา 3 ข้อ

      ดูเฉลยคำตอบ
      ตัวอย่างกฎเหล็ก JSON ที่เข้มงวดกว่า:
      1. ชื่อคีย์ (Key) ทุกตัวต้องครอบด้วยเครื่องหมายอัญประกาศคู่ (Double Quote ") เท่านั้น ห้ามละเว้นหรือใช้เดี่ยว '
      2. ห้ามมีฟังก์ชัน/เมธอด (Method) เก็บใน JSON โดยเด็ดขาด
      3. ค่าประเภท undefined และ NaN จะต้องไม่มีอยู่ โดยค่าว่างเปล่าต้องระบุเป็น null แทน

    10. หากใช้คำสั่ง JSON.stringify() กับออบเจ็กต์ที่มีพร็อพเพอร์ตี้เป็นฟังก์ชัน (Method) รวมอยู่ด้วย ผลลัพธ์สุดท้ายที่ได้จะเป็นอย่างไร?

      ดูเฉลยคำตอบ
      ผลลัพธ์ของสตริง JSON จะถูกแปลงออกมาตามปกติ แต่ตัวพร็อพเพอร์ตี้ที่เป็นฟังก์ชัน (Method) และพร็อพเพอร์ตี้ที่มีค่าเป็น undefined จะถูก ตัดออกทิ้งไปโดยอัตโนมัติ จากก้อนสตริงผลลัพธ์
